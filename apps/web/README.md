# ShopTheVlog Web App

This package contains the public web app and server routes for ShopTheVlog.

## Local Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Common Commands

```bash
npm run dev
npm run build
npm run start
npm run test
npm run test:e2e
```

## Deployment

Production deployment targets Google Cloud Run, not Vercel.

See the full runbook at [../../docs/runbooks/gcp-production-stack.md](../../docs/runbooks/gcp-production-stack.md).
